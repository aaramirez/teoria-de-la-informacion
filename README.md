# Teoría de la información

La medida de Shannon y lo que permite: entropía, información mutua, compresión con Huffman, codificación aritmética y LZ, compresión con pérdida, capacidad de canal y códigos correctores de Hamming a LDPC, con un compresor que se construye en el curso.

**Ver en línea:** https://aaramirez.github.io/teoria-de-la-informacion/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
